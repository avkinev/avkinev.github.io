COPYRIGHT PATCH v8 — THREE FILES

This patch is for the GitHub Pages site avkinev.github.io based on v6
(the version in which ru.md and en.md are editable).

Replace ONLY these three files in the ROOT of your main branch:
  ru.html
  en.html
  style.css

Do NOT upload a folder containing them. Do NOT replace ru.md/en.md.
Your stories and translations remain unchanged.

IMPORTANT: GitHub should show 3 changed files in the new commit.

AFTER COMMIT:
  1. Wait for GitHub Actions / Pages deployment to succeed.
  2. Open https://avkinev.github.io/ru.html and use Ctrl+F5.
  3. Scroll below story #1: the copyright notice is visible.
  4. Press Ctrl+P. You should see a diagonal watermark across the text.
  5. Test both language pages.

WHY THIS IS DIFFERENT:
Copyright is now added by Jekyll when GitHub builds the page.
There is no reliance on JavaScript or the structure of the live page.
Whenever a story heading begins with '## ' in ru.md/en.md, a new notice
is inserted automatically after its text. The first '## ' heading is the
introduction, which gets no story notice. Do not use additional '## '
subheadings inside a story: use '### ' instead.

Print watermark deters casual republication; it cannot stop a visitor
from extracting HTML, making screenshots, or disabling print styles.
